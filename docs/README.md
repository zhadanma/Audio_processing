## 关键决策速览

- **形态**：Windows 11 桌面应用，Python 3.11 + PySide6（Qt6）
- **分离**：`htdemucs_6s` 一级六轨（人声/鼓/贝斯/吉他/钢琴/其他）+ DrumSep/Karaoke 级联细分
- **播放**：sounddevice 实时多轨混音，逐轨增益/静音/独奏零成本生效
- **存储**：FLAC stem 文件 + 自包含项目文件夹（`project.json`）
- **导出**：WAV/FLAC（MP3 视 ffmpeg 可用性），播放与导出共用同一混音数学
